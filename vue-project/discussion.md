# 討論記錄 — 貪食蛇遊戲開發

## 總覽
以 Vue 3 + TypeScript + Vite 建構貪食蛇遊戲，分三階段開發。

---

## 三大開發階段

### Phase 1: HTML 靜態原型
- 建立 `snake-static.html`，純 HTML/CSS/JS
- Canvas 20×20 網格，每格 20px
- 蛇身、食物、分數、開始/重置按鈕、鍵盤控制 (WASD/方向鍵)
- 碰撞偵測（邊界、自身）、勝利條件（填滿地圖）
- 先確認邏輯無誤再移植到 Vue

#### 調整記錄
- 地圖背景 (`#1e2a4a`) 與頁面背景 (`#0f0f23`) 要不同色，地圖須比頁面淺
- 網格線 (`#4a6a8a`) 與地圖背景要有足夠對比，避免顏色太相近

### Phase 2: Vue 移植 + 資料層
- 將靜態頁面移植為 `src/components/SnakeGame.vue`
- 使用 Vue 3 Composition API (`ref`, `onMounted`, `onUnmounted`)
- 響應式資料：`snake`, `food`, `direction`, `score`, `gameStatus`
- Canvas 渲染綁定 data
- TypeScript 型別定義 (`Point` 介面)

### Phase 3: 功能擴充
#### 排行榜 (Leaderboard)
- localStorage 持久化儲存
- 顯示前 10 名
- Game Over 時若分數達標，彈出輸入框讓玩家留名
- 輸入名稱時 WASD 控制被禁用（避免干擾）

#### 速度提升
- 每 50 分升一級 (Level)，間隔從 150ms 逐步縮短
- 最低間隔 100ms（後來從 60ms 調升，避免太快）

#### 複數食物
- 食物數量 = 等級 + 1，上限 6 顆
- 每顆食物不同色（HSL 色相環）
- 必須吃完當輪**所有食物**，才生成新一批

#### 四種遊戲模式
| 模式 | 規則 |
|------|------|
| **普通** | 原版：撞牆/撞身死亡 |
| **雙頭蛇** | 吃到食物時，舊蛇頭移到尾巴位置（蛇仍增長） |
| **無邊界** | 穿牆繞到另一側，只會撞身死亡，吃滿地圖獲勝 |
| **爆炸** | 普通規則 + 地圖隨機生成 3×3～7×7 爆炸區，閃爍 1 秒後爆炸 |

- 上方 tab 切換模式，切換時自動重置遊戲
- 爆炸模式使用 `requestAnimationFrame` 實現平滑閃爍動畫

### 後續調整 (第 2 輪)
#### 排行榜確認流程
- Game Over 後先彈出「是否要記錄到排行榜？」(是/否)
- 選「是」才進入輸入名稱畫面，選「否」直接關閉

#### 雙頭蛇模式修正
- 改為**整個蛇身陣列反轉** + 方向也反轉，蛇頭真正與蛇尾互換

#### 爆炸模式改良
- **數量遞增**：炸彈生成間隔隨等級縮短 (4000ms → 最快 2000ms)
- **炸掉身體**：爆炸時若蛇身在範圍內，從尾部移除 4 節（蛇 <= 3 節才死亡）
- **爆炸停頓**：閃爍 1 秒後，亮紅/橘光停留 300ms 再消失，有爆炸視覺感

### 後續調整 (第 3 輪)
#### 雙頭蛇方向反轉 Bug 修復
- `nextDirection` 用了已反轉的 `direction` 導致二次反轉 → 用暫存變數 `revDir` 修正
- 改為朝身體反方向前進：反轉後計算 `awayDir = head - body[1]`，確保頭朝遠離身體的方向走

#### 暫停功能
- 遊戲進行中可按 Escape / P 或點擊「暫停」按鈕
- 暫停時：WASD 失效、爆炸計時停發、畫布覆蓋「⏸ 暫停」遮罩
- 繼續後恢復正常

#### 排行榜分模式
- 每筆紀錄儲存 `mode` 欄位
- 排行榜上方有 4 個模式分頁，可切換檢視
- 切換遊戲模式時排行榜自動跟隨

### 後續調整 (第 4 輪)
#### 模式按鈕、排行榜按鈕加寬
- `.mode-tab`、`.lb-mode-tab` 增加 `padding` 並加入 `white-space: nowrap`，防止「雙頭蛇」換行

#### 程式註解
- 為 `SnakeGame.vue`、`App.vue`、`snake-static.html` 加上英文註解（區塊標題、關鍵邏輯說明）

#### 暫停爆炸 Bug 修復
- 暫停中 `draw()` 的爆炸過期邏輯仍會對蛇造成傷害（移除身體段）
- 如果蛇身 <= 3 段會觸發 `gameOver()`，導致恢復後狀態異常
- 修復：在爆炸傷害判斷加上 `!isPaused.value` 條件
